https://github.com/cnc24/crepe. Do not post confidential terms or customer data in
public issues. A written agreement must identify the parties, rights, price,
term and any support obligations. This repository does not invent those terms.

## Publication and license scope

This publication repository starts from a fresh snapshot under the license in
LICENSE. Earlier private development history, tags and binary assets are not
included. The owner states that those development versions were not previously
published or distributed to third parties. Private backups are not part of this
publication repository.

The license applies only to material the licensor has the right to license.
It does not revoke any rights previously granted to an actual recipient.
Third-party components keep their original terms. References to possible
licenses in the original design are historical planning discussion, not a
license grant for Crepe; LICENSE governs this snapshot.

## Third-party code and contributions

Dependency/runtime licenses and notices remain in THIRD-PARTY-NOTICES.txt and
legal/. The project license does not override them. Redistribution must satisfy
the relevant dependency terms as well as Crepe's applicable license.

Accepting external contributions requires clarity about the contributor's
rights and any permission needed for separate commercial licensing. A sign-off
or a GitHub pull request alone should not be treated as granting unlimited
relicensing rights. No contributor agreement is established by this guide.

These custom terms implement the requested policy and have not received an
independent legal review. In particular, the boundary between permitted
contractor assistance and paid managed services, contributor rights and
any prior grants should be reviewed before commercial licensing or a public
launch. The license provides no guarantee of enforceability in every jurisdiction.
