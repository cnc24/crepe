# Roadmap and release scope

The maintained roadmap is [the repository roadmap](../ROADMAP.md).
The earlier private-prototype plan has been superseded; it must not be used as
an inventory of missing capabilities in current releases.

Use [target acceptance](TARGET-ACCEPTANCE.md) for the October v1 architecture,
[design status](DESIGN-STATUS.md) for intentional limits, and
[the operating guide](OPERATIONS.md) for runnable commands and compatibility.
[The changelog](../CHANGELOG.md) records shipped changes. A feature present on
main is only available through `crepe update` after its release is published.
